# ✦ CampusCopilot

### Your campus, organized. Your decisions, always in control.

CampusCopilot is an MCP-powered campus assistant designed to help students manage college notices, assignment deadlines, examinations and events from one place.

It transforms scattered campus information into actionable tasks and calendar suggestions, while keeping students in control through an approval-based workflow.

## 🚀 Key Features

- **Smart Notice Processing:** Submit college notices and extract possible tasks and events.
- **Deadline Management:** Identify assignment and submission deadlines.
- **Event Management:** Organize examinations, meetings and campus events.
- **Approval System:** Approve or reject every suggested action before it is added.
- **Undo Functionality:** Reverse previously approved actions.
- **Daily Digest:** View important upcoming activities.
- **Activity Log:** Maintain a record of approvals and rejections.
- **Responsive Dashboard:** Simple interface accessible across devices.

## 💡 How It Works

1. Student submits a college notice or circular.
2. CampusCopilot processes the notice and identifies possible actions.
3. Suggestions appear in the approval center.
4. Student reviews and approves or rejects suggestions.
5. Approved items appear in the student's schedule and dashboard.

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Model Context Protocol (MCP) – planned integration
- GitHub Pages – frontend hosting

## 🎯 Problem We Solve

Important campus information is scattered across emails, WhatsApp groups and college notices. Students often miss deadlines, examination updates and important events.

CampusCopilot aims to bring this information together through an intelligent, student-controlled assistant.

## 🌟 Innovation

Unlike ordinary reminder applications, CampusCopilot focuses on understanding campus notices and converting them into useful actions with mandatory student approval.
